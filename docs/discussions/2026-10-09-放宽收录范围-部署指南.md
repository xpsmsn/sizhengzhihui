## 三、让存量文章按新规则更新（批量重评估）

**新规则只对"之后新抓取的"内容自动生效。** 已有的文章还带着旧判断，需要重跑一遍。

采用「**批量重新评估**」而不是「重新抓取」——原文不用重抓，只重算 AI 判断（原因见方案文档第四节）。

### 第 1 步：试算（不改动，只看数量）

```bash
cd /volume2/docker/aihot/sizhengzhihui
docker compose exec -T worker node scripts/reanalyze.ts
```

输出示例：`[试算] 将重新评估 218 篇文章。`

### 第 2 步：确认额度后执行

先到后台「设置 → 付费请求上限」确认额度，再执行：

```bash
docker compose exec -T worker node scripts/reanalyze.ts --run
```

也可只重评估某一个信源：

```bash
docker compose exec -T worker node scripts/reanalyze.ts --run moe-jyyw
```

### 第 3 步：等待与查看

- 脚本把文章重置为待处理，**worker 的 sweep 会在几分钟内逐批重新入队**，无需手动触发。
- 在后台「运行」页观察进度；完成后首页精选与分类会按新规则刷新。
- 全量重评估会产生模型调用费用，耗时取决于文章数。

> 小范围先试：想先看效果，可对单个信源执行，满意后再全量。

## 四、推荐新增信源（后台添加，不需要改代码）

**新分类要真正有内容进来，还需要补信源。** 现有 22 个信源偏思政；教育、领导、高校方向建议补：

| 方向 | 推荐信源 | 说明 |
|------|---------|------|
| 教育 | 教育部·新闻/工作动态、中国政府网·政策、中国教育报 | 教育部各栏目与政府网政策页 |

| 高校 | 985/211 高校官网新闻、各校学工/宣传部 | 需逐校配置选择器 |

**添加方法（无需重启）**：登录后台 → 左侧「信源」→「新建信源」，填 URL 与选择器，保存后 worker 自动按间隔采集。

⚠️ 注意：不同网站结构差异大（如中国政府网政策页是 JS 动态加载、教育部用非标准 class），**新建后请到信源详情页看一次采集结果**，若报 `no items matched` 需调整选择器（`itemSelector` / `linkSelector` / `titleSelector` / `publishedAtSelector`）。有 RSS 的站点优先用 `kind: rss`，免配选择器。

## 五、回滚
