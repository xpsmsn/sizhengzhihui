# 思政智汇 · 本次改造记录（2026-10-09 ~ 2026-10-11）

本记录汇总近几次会话对站点的改动，作为部署、排障与后续维护的依据。整体分五个方向：**收录范围放宽、界面与分类、时间与日期、报告模块重构、信源日期修复**。

---

## 一、收录范围放宽（分类扩展）

- **分类从 5 类扩到 8 类**（`industry/taxonomy.ts`）：
  - 原有：讲话精神 / 政策文件 / 改革部署 / 育人实践 / 理论视野
  - 新增：**教育要闻（education）/ 领导活动（leadership）/ 高校动态（campus）**
- **标签词表扩充**：分类标签加 3 个（教育要闻、领导活动、高校动态）；主题标签加 基础教育 / 职业教育 / 高等教育 / 教育数字化；近义词同步补充。
- **提示词同步**：`content-understanding.md`（itemType 描述与标签白名单）、`selection-score.md`（放宽噪声规则：教育、高校内容不再一律压到 `sig≤2`）、`structure.md`（首标签说明）。
- **前端**：筛选栏只显示**有条目的分类**（`categoryCounts`，见下）；移除与"全部"重复的"一手"筛选。

> 详细方案见 `docs/discussions/2026-10-09-放宽收录范围方案.md`。

## 二、界面与分类

- **筛选栏隐藏空分类**：给 `TimelineResponse` / `PoolResponse` 增加 `categoryCounts`，前端 `CategoryTabs` 只渲染有内容的分类（`packages/contracts`、`publication/timeline.ts`、`publication/pool.ts`、`features/feed/Filters.tsx`、`routes/home.tsx`、`routes/all.tsx`）。
- **移除"一手"筛选**：`features/feed/Filters.tsx`。
- **首页"近期关注"链接修复**：无 story 的文章改用 `itemId` 链接到 `/items/<id>`。

## 三、时间与日期（时区修复）

- **根因**：列表页日期只有日期（如 `2026-10-09`），`parseLooseDate` 原先把"纯日期"按 **UTC 午夜**解析 → 北京时间显示 08:00；真实时间只在详情页。
- **修复**（`packages/backend/src/sources/dates.ts`）：
  1. 纯日期改按**信源时区**解析（北京午夜），不再当 UTC；
  2. 支持"日期-时间"用**短横线**分隔（政府网 meta `2026-10-09-18:16:00`）。
- **取精确时间**：给政府网 + 17 个思政网信源加"**详情页日期为准**"（`detail.publishedAtAuthoritative`），采集时多取一次详情页拿精确时间。

## 四、报告模块重构（取消日报 → 政策解读）

**决策**：取消日报；政策解读触发线 **score ≥ 82**；展示位在老日报页；周报出刊不变（周一 10:00）；同事件取最高分合并；不推飞书。

- **取消日报出刊**（`reports/compose.ts`）：`composeDueReports` 只补周报/月报；**周报/月报改为直接从精选集取数**（不再汇编日报）。
- **空周期不再报错**：周期没有够格内容时跳过、不抛错（修复 `reports.compose` 长期失败，根因是"非回灌精选"为空时抛异常并反复重试）。
- **政策解读模块**：
  - 提示词 `industry/prompts/insight.md`：时政 + 高校双视角，**基于原文再表达、只输出解读（规避版权）**，背景 / 要点 / 对辅导员的启示，且不得与原文或其他条目矛盾。
  - 数据表 `insights`：`database/migrations/0058_insights.sql`（表）+ `0059`、`0060`（并发索引各一条语句）。
  - 生成 `packages/backend/src/reports/insights.ts`：`generatePendingInsights()` 扫描"已精选、score ≥ 82、其事件还没有解读"的条目，**同事件取最高分合并成一篇**。
  - 触发：定时任务 `reports.insights`（每 10 分钟，`apps/worker/src/schedules.ts`）。
  - 展示：`/daily` 改为「**周报入口 + 解读流**」（`routes/insights.tsx`），详情 `/daily/:articleId`（`routes/insight-detail.tsx`）；接口 `/api/site/insights` + `/:articleId`；导航「日报」→「政策解读」。

> 详细方案见 `docs/discussions/2026-10-09-报告模块重构方案.md`。

## 五、信源日期修复（历史遗留）

- **根因**：所有思政网信源的详情页日期选择器写成了 `.date`，而详情页实际是 `.titbox .time` → 详情页取不到日期；列表页偶缺失的日期补不上，回灌文章被 `publish.ts` 的"回灌需有日期"规则排除。
- **修复**：把 17 个思政网信源的详情页选择器改为 `.titbox .time`；`maxFetches` 提到 30；重新采集。
- **历史遗留**：用一次性脚本 `scripts/refill-publication-dates.ts` 回填（先补空日期、后补精确时间），共 73 条。

> 部署与排查见 `docs/discussions/2026-10-09-放宽收录范围-部署指南.md`。

## 六、一次性运维脚本（`scripts/`）

| 脚本 | 用途 |
|------|------|
| `reanalyze.ts` | 改规则后批量重评估存量文章（试算 / `--run`） |
| `refill-publication-dates.ts` | 为空日期 / 午夜日期文章回填（精确）发布日期（试算 / `--apply`） |
| `clear-daily-reports.ts` | 清除已取消的日报数据 |

## 七、部署要点

- **多语句迁移会失败**：在线迁移安全规则要求**每个迁移文件一条语句**、索引必须 `CREATE INDEX CONCURRENTLY`。
- **改了 `industry/`、`site/`、后台代码后**：上传到 NAS 源目录，`docker compose up -d --build`。
- **新迁移**：`setup` 服务在 `up` 时自动执行。
