# 2026-11-17 品牌焕新与 MCP 特色化改造记录

## 概述

本次改造完成四件事：全局模型切换、主题体系重组、UI 品牌焕新、MCP 站点特色化。所有改动已于当日 build 部署验证。

## 一、模型切换：小米 MiMo → DeepSeek

- 背景：MiMo（mimo-v2.6-flash）做思政材料分析频繁报 high risk，决定全局换 DeepSeek。
- 改动：`.env` 的 `LLM_BASE_URL=https://api.deepseek.com/v1`、`LLM_MODEL=deepseek-flash`、`LLM_EXTRA_JSON={"thinking":{"type":"disabled"}}`。原配置备份 `.env.bak.20261117`。
- **关键坑**：DeepSeek 的 `thinking:disabled` 不生效、仍会推理，推理会吃掉 `max_tokens` 额度导致输出截断（表现为解读段落不全、要点断在半句）。**必须保留 `LLM_REASONING_TOKENS=4000`**。
- 部署生效方式：`docker compose up -d --force-recreate api worker`（仅 restart 无效，env 只在重建时注入）。
- 验证：文章 `oue5ua64vu99jyygk2hvtanyp` 解读重生成，八个部分齐全、无半句截断。
- 解读重生成方法：`DELETE FROM insights WHERE article_id=...`（变回待生成）+ 清零 `receipts.attempts`（同版本失败 3 次会被封印跳过），worker 的 `reports.insights` 每 10 分钟自动补写。全量重生成可改 `industry/prompts/insight.md` 触发版本号变化（全部重新计费，慎用）。

## 二、主题体系重组：3 组 10 主题 → 4 组 12 主题

- 心理 85 vs 资助 33（不均衡）→ 合并为「帮扶育人」；就业 68 + 生涯 31 → 独立「就业与生涯」。
- 新体系：

  - 学生成长：帮扶育人 / 就业与生涯

  - 形势与热点：党建与从严治党 / AI与教育数字化
- 改动文件：`industry/topics.json`（全量重写）、`industry/taxonomy.ts`（`TOPIC_TAGS` 换 12 新标签 + `TAG_SYNONYMS` 按新体系重写，旧标签词全部归并映射，如立德树人→三全育人、学生育人→帮扶育人）。`CATEGORIES` 8 个类别 key 不动（上线后不可改）。`structure.md` 无需手改（`{{topicTags}}` 自动注入）。

## 三、UI 品牌焕新：纸墨配色 + 霞鹜文楷 + 图标

- 配色（`apps/web/app/app.css`）：弃用 AIHOT 冷青系（#176b75/#12ccd8），改「纸墨」——亮色宣纸米白底 #f8f6f1 + 墨字 #26221c + 朱砂点缀 #9e2a25；暗色墨底 #1c1a17 + 米白字 + 暖金点缀 #d9a862。组件走语义 token（bg-accent 等），改 CSS 变量即全局换色。
- 字体：字标与页面大标题（`[data-page-title]`）用 LXGW WenKai Bold（OFL 开源楷体），依赖 `lxgw-wenkai-webfont@1.7.0`（582 个 unicode-range 分片按需加载，必须同步 `package-lock.json`）；正文仍用 sans。
- 报头 nameplates 用文楷重生成：`.tmp/nameplates-wenkai.py`（fontTools 复刻 `scripts/nameplates.ts` 几何 H=220/GAP=0.085H/MARGIN=12）。**坑**：`@fontsource/lxgw-wenkai` 只有 latin 子集不可用；解析 unicode-range 必须按 `@font-face` 块切分，跨块正则会吞入后续 CSS 报错。
- 图标（`site/brand/`）：从用户 840×840 PNG（红金徽章：书本+红星+旗帜）派生 icon.png(512)/icon-192(192)/apple-icon(180 白底 RGB)/favicon.ico（**16/32/48/64 四帧**，用 `sizes=[...]` 参数从大图生成，append_images 方式会只写单帧）。`manifest.webmanifest` 配色改 #26221c。`Logo.tsx` Wordmark 红点→朱砂五角星 SVG（fill var(--accent)）。
- 文案：`site/site.ts` footerNote「由 AIHOT 开源框架驱动」→「思政智汇 · 汇集思政动态，服务育人一线」。
- favicon 更新后旧图标残留是浏览器缓存（favicon 缓存极顽固，仅影响本人浏览器，无痕窗口可验证），服务端按 `site/brand/` 固定文件名服务，无需配置。
