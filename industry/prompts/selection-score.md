- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于发布、部署、试点、落地、总结还是回顾阶段”。然后从以下 7 类中选择最贴近的一类：

- `leader_speech`：中央领导同志关于思想政治工作、教育的重要讲话、指示、回信、贺信或考察讲话
- `policy_release`：中办国办、教育部等发布的教育、思想政治工作、德育、思政课相关文件、意见、方案、办法及其权威解读
- `case_practice`：高校（尤其是 985、211 等重点高校）在思政课、课程思政、三全育人、辅导员工作、教育教学与内部治理等方面的具体做法、经验或改革案例
- `theory_research`：理论文章、研究报告、课题成果或对思想政治工作规律的原创研究
- `opinion_commentary`：一线教师、干部或学者的观点、经验判断、工作复盘或访谈
- `work_notice`：会议、培训、论坛、评比、申报、公示等事务性通知与安排
- `publicity_report`：活动通稿、表彰宣传、领导视察行程、工作动态等宣传报道

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在思政工作的时间线上是节点、这一时期值得知道的变化，还是当天脚注。不要把“辅导员能马上用上”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。新要求、新举措、新经验、新结论或新问题才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方发布足以证明“印发、部署、召开、回应”这一动作，但不能自动证明宣传中的成效。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关，或至少能理解它为何重要、典型、有借鉴意义。
5. `act` 可用性：读者是否能马上参照使用、调整做法、迁移经验或用于本单位工作。纯精神和重大政策的 act 低是正常的，不应反过来抹掉 sig。

不要把五轴先求平均；不要改权重；不要把多个普通理由堆成高分；不要为了靠近整十或任何想象中的门槛而改写计算结果。

## 品味规则

### 必须正常评价的价值

- 中央领导同志关于宣传思想工作、思想政治工作、教育的重要讲话、指示、回信，以及明确提出方向、原则或要求的新表述。
- 中办国办、教育部等正式印发、部署的思想政治工作文件与方案，以及权威机构对口径、边界的官方解读。
- 985、211 等重点高校在思政课建设、课程思政、三全育人、辅导员队伍、心理健康、资助育人、就业引导、学风建设等方面具体、可迁移的做法与经验。
- 国家教育方针、教育规划与各级各类教育改革发展的政策、部署和要闻，以及教育部及省级教育主管部门主要负责人的教育相关活动与指示；高校在教学、科研、人才培养、社会服务等方面的可借鉴动态与做法。
- 能改变从业者对工作路径、方法边界或现实问题判断的调研数据、典型问题与原创理论框架。
- 可信的新事实、反直觉的调查结果、有代表性的个案或可复用的工作方法，只要读者一眼能理解“为什么值得关注”，可以形成独立高价值。
- 政策文件随附的权威问答、图解、答记者问，只有在提供了文件本身没有明确给出的边界或适用解释时，才按其真实增量正常评分。

### 必须压住的噪声

- 一般会议、培训、论坛、评比、申报、公示等事务性通知与安排，没有可迁移内容或政策信号，`sig ≤ 3`。
- 客户式或个案宣传：某校举办某活动、某单位开展某主题教育的通稿，若没有可借鉴的做法、数据或机制，`sig ≤ 3`。
- 表彰、展播、点赞、经验交流“巡礼式”汇总而无具体方法，`sig ≤ 3`。
- 宣传软文、招生推介、活动预告、招聘、征文征稿、模糊工作展望，`sig ≤ 2`。
- 只有预告、即将举办或“正在筹备”，没有实质内容与可验证安排，`nov ≤ 3` 且 `cred ≤ 4`。
- 单篇观后感、学习心得、口号式表态，没有新事实、新方法或普遍适用性，`nov ≤ 3` 且 `sig ≤ 4`。
- 新闻摘要合集、周报、月报等多事件打包且没有单一焦点，`sig ≤ 3`。
- 与教育、高校工作无关的纯社会新闻、娱乐八卦、财经行情、体育赛果、一般校园后勤保障或校庆晚会等，若被误放进来，`sig ≤ 2`。
- **注意**：教育政策、教育改革、教育要闻、高校办学与育人的动态与做法（含 985/211 高校的经验），不在压缩之列，按其真实增量正常评价；即使不属于思政专项，只要对辅导员、思政教师和院系管理者有参考价值，就正常给分。压住的只是"纯活动通稿、无实质做法"这一类。
- 宏大评论若没有新事实、新因果或可复用框架；单纯表态、表态式转载、口号标语，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、转载或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的表述、要求或效果补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或内容，按这个较弱事件评分；不要替材料补全一个更强的故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 最高层级的精神指引本身就是重大变化。中央领导同志明确提出的新要求、新方向，即使材料是一段短转述，也不能按“表态转发”或“二手报道”压低 `sig`、`nov`、`reson`。
3. 已由权威渠道正式印发并公开的思想政治工作文件，应按政策事件判断；其中包含明确适用范围、责任主体或工作路径时，它同时提供了可理解、可执行的政策信号，不得套用“一般通知”上限，也不得等同于一校一地的活动通稿。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“中央文件印发 + 某校落实报道”“政策口径明确 + 一家媒体解读”，不能只抓住落实报道或解读身份。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一校内经验或宏大推断制造事件价值。只有正文支持的新事实、新要求或可迁移方法进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
