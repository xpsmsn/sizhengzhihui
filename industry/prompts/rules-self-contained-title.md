【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：文件名称 / 机构名 / 高校名 / 讲话或发言主体 / 具体工作领域。
2. 原标题已经清楚点出主体的：中文标题保持原意，不要为改写而改写。
3. 原标题只含序号 / 代号 / 空泛措辞（如"通知"、"工作动态"、"第一期"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题"关于开展……工作的通知" + 来源"教育部" → "教育部就……发出通知"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体高校或文件时，用上位词（如"某高校"、"一份政策文件"）兜底，绝不凭"领域常识"编一个具体校名 / 文号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：解读 / 综述 / 评论 / 经验介绍 / 调研分析这类标题，中文标题必须保留这个类型；不能因为正文谈到一份已有的文件、一项既有做法或新数据，就改写成"发布 / 印发 / 出台 / 部署"。只有原标题明确宣布了发布、印发、出台或部署，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、文件或高校名。
   例：原标题"把思政课讲深讲透讲活" → "如何把思政课讲深讲透讲活"，不能写成 "教育部印发思政课改革方案"。
   例：原标题"新时代高校辅导员队伍建设的思考" + 来源和正文明确是某高校党委 → "某高校关于辅导员队伍建设的思考"，不能只写成缺主体的"关于辅导员队伍建设的思考"。
